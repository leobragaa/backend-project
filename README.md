## Dependências

|        Nome | Versão   | Doc                                      |
| ----------: | -------- | ---------------------------------------- |
|     Node.js | v24.21.0 | https://nodejs.org/docs/latest/api/      |
|     Nest.js | v12.0.3  | https://docs.nestjs.com/                 |
|     TypeORM | v1.1.1   | https://typeorm.io/docs/getting-started/ |
| PostgresSQL | v18      | https://www.postgresql.org/docs/         |

## Project setup

```bash
$ npm install
```

## Compile and run the project

```bash
# watch mode
$ npm run start:dev
```

## Deployment

```bash
$ npm install -g @nestjs/cli
```
